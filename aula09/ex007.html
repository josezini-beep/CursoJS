para pegar um elemento podemos usar a marca com o id, a classe ou a tag do elemento

Para pegar um elemento pelo id usamos o document.getElementById('id do elemento') e para pegar um elemento pela classe usas o document.getElementsByClassName('nome da classe') e para pegar um elemento pela tag usamos o document.getElementsByTagName('nome da tag')
